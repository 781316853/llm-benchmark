交叉模型矩阵

同一模型在多项基准中的成绩(高亮表示多榜命中);默认按综合分降序,仅命中≥4 榜的模型参与排名并编号;命中 3 榜的「参考」模型按各榜成绩与排名模型比对落入相应名次区间(不计算综合分,序号计「—」,仅显示数据);命中 ≤2 榜的模型不在总览展示;「榜单基准」组尾的 HLE / GPQA 两列为权威基准参考分,仅展示、不计入综合分与命中数;「实测」组首的 ModelDial 列为第三方独立实测的综合能力分(后端 40% + 前端 30% + 知识 30%);点击表头可切换排序,按某评测排序时仅显示该评测有数据的模型

阅读说明

  • 「梯队」根据上榜模型数量与综合分分布动态分档(金字塔分档),将全部模型按综合分降序,以 S+=1、S=3、A+=5、A=7、B+=9、B=11、C+=13、C=15、D+=17、D=19、E+=21、E=剩余 的金字塔权重分配至 S+ / S / A+ / A / B+ / B / C+ / C / D+ / D / E+ / E 共 12 级。高档少、低档多,梯队边界随数据变化动态浮动,不设固定阈值。鼠标悬停梯队标签可查看精确综合分;勾选「显示综合分」可在梯队旁直接显示数值。综合分计算方式:先执行「一榜豁免」——剔除模型在场基准组中最弱的一组(单榜失常不全盘否决),其余按权重加权平均(DeepSWE 18%/Code Arena·WebDev 16%/llm2014 12%/AI 能力·前端 12%/AI 能力·后端 12%/Terminal-Bench 12%/ModelDial 12%,llm2014 与 AI 能力同为个人专项测试口径,缺失榜单的权重自动回流至在场榜单);再按 7 个计分组的在场数给予完整度奖励(全勤 7 组 +3 分、6 组 +1.5 分、≤5 组不计,奖励补全数据而非惩罚缺榜);最后减一致性折减(跨榜标准差越大折减越多,每点σ扣0.15分,上限1分)。列表默认按综合分容差分组排序:差距<1.5分的模型视为同档,同档内优先排列命中数多、跨榜一致性高的模型。
  • 「命中」表示该模型在对应基准组中进入榜单,6/6 表示六项基准(DeepSWE / llm2014 / Code Arena·WebDev / Terminal-Bench(4.0/3.0/2.1) / AI 能力 / ModelDial)均有排名;HLE / GPQA 权威基准仅作参考列展示,不计入命中数。
  • DeepSWE 为百分比,分数后的「$X」为该模型在 DeepSWE 的单次任务平均成本(美元); llm2014 为按各项目等级均值归一化的综合分(0-100,月内均值最高 100、最低 0,中间按等级差距线性分布;均值完全相同的模型按源站排名先后微调区分,保证人人不同分),其明细单元格为「扣分数/档位」,2026-08 起等级单元格可含单任务测试成本(如「7/A+(90.52)」表示扣 7 分、A 档、成本 ¥90.52); Code Arena · WebDev 为 LMArena 前端竞技场的 Elo 评分(社区匿名盲测投票,分值越高越好,矩阵列显示原始 Elo),参与综合分主基准组时按快照内 min-max 归一化到 0-100; Terminal-Bench 4.0/3.0/2.1 为终端命令行 Agent 评测成绩(多版本合并为一个基准组,**优先以最高版本为代表**:即 4.0>3.0>2.1,版本内取该模型最优成绩),计入综合分(权重 12%)与命中数,单元数字旁附版本标签(v4.0/v3.0/v2.1);由于不同版本难度与口径不同(如 2.1 为厂商自报分,分数普遍虚高于 4.0 官方实测),综合分按「以 4.0 为基准折算难度系数」的口径计入:3.0/2.1 的分数按跨版本共有模型折算为**4.0 等效分**(难度系数每日随数据自动重算,当前约 3.0×1.1、2.1×0.3,即 2.1 的 88 分约相当于 4.0 官方 26 分),全池统一 min-max 归一化到 0-100,低难度版本的虚高分不再追平 4.0 头名;列表展示的仍是该代表版本的**原始分**,难度差异一目了然;口径提醒:4.0/3.0 为 agent×model 解决率、2.1 为 llm-stats 归一化自报分(已换算为%),4.0 与 2.1 另有 datalearner 镜像补充官方未收录模型(只补缺、不覆盖官方口径),完整条目见「权威基准测试」页(Terminal-Bench 单章节内切换版本查看,默认 4.0); AI 能力·前端/后端为 atmeplz 四方向榜的方向分(0-100,天然以 100 为参考,越高越好),前端=中式建筑 25%+体素山水 25%+前端网页 40%+黑洞模拟 10%,后端=超级 MES 100%; NL2Repo-Bench 为长程仓库生成基准(给定需求文档从零生成可安装 Python 库),test-pass-rate(%)由多源(llm-stats + benchlm.ai + 官方论文评测表 + datalearner 厂商发布)合并取最高;**自 2026-09-19 起不再计入综合分与命中数,已移出总览矩阵**(原权重 9%),改为仅在「权威基准测试」页展示; ModelDial 为第三方独立实测的编码智能体能力榜,矩阵列显示其综合分(0-100,后端与测试 40% + 前端与交互 30% + 知识与推理 30% 加权),同一模型按推理强度分档多次测试后取最高分配置入榜,计入综合分(权重 12%)与命中数;格内悬浮可查看三分项与耗时/费用,完整主榜与 52 条 config 明细见「ModelDial」页(费用与耗时为源站后端单轴口径,故低于源站主榜显示值)。
