  • 本页汇总 Codex / Claude Code / OpenCode / Kimi Code / Qoder CN / Qoder CN IDE / TraeCode / TraeWork / ZCode / CodeBuddy / WorkBuddy 十一个 Agent 工具的官方更新日志,每个工具只显示最近一次更新,正文保留源站完整内容(不摘要),右上角「查看源站 ↗」跳到该条更新在源站的原文。
  • 数据文件仍保存各源可得的全量历史;上方的近 14 天 / 近 30 天 / 全部切换的是「最近一次更新要多久以内才算新」—— 超出范围的工具不显示卡片,改为提示其最近一版发布于何时。窗口按自然日从今天往前推算,与数据是否刷新成功无关。
  • 英文条目由免费机器翻译接口(MyMemory)自动译成中文,与全站数据一样每日刷新 2 次。只译各工具当前显示的那一条(最多 11 条,其中 Claude Code 单条发布说明可达 2 万字符,需分轮补齐),同一份发布说明只译一次、之后长期复用不再请求;尚未译出的条目标注「原文」并保留英文。
  • 只收录正式发布版本:alpha / beta / rc / nightly 等预发布版一律不入库(实测 Codex 单次抓取的最新 10 个 release 有 9 个是 alpha 预发布版,全收会淹没整页)。
  • Codex / Claude Code / OpenCode / Kimi Code 取自各自 GitHub Releases 官方接口(Kimi 官方文档站的更新日志是客户端渲染、抓不到内容);Qoder CN 与 Qoder CN IDE 取自 Qoder CN 文档站的两张更新日志页(桌面端 0.4.x 与 IDE 1.32.x 是两套编号,故分两卡);TraeCode / TraeWork 各取 Trae 文档站的独立日志页(docs.trae.cn 的 ide_changelog / work_changelog,一次发布一个日期标题、可深链到那次发布;抓不到时转国际站 trae.ai 备源 —— 备源是多产品线混排,按标签挑出本卡那条线,TRAE APP 一类不收录);ZCode / CodeBuddy / WorkBuddy 取自各官网更新日志页。条目上的标签是源站自带的分类。
  • 随全站数据每日自动刷新 2 次。某个源改版或抓取失败时,该工具卡片会标注「数据滞后」并沿用上一次成功抓到的条目,同时保留跳转源站的入口;若显示「最近一次更新在 X,超出当前时间范围」,表示源站确实在那之后没有发布新版本(例如 TraeWork 最近一版在 8 月 21 日)。
