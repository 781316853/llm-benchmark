阅读说明

  • 「梯队」根据上榜模型数量与综合分分布动态分档(金字塔分档),将全部模型按综合分降序,以 S+=1、S=3、A+=5、A=7、B+=9、B=11、C+=13、C=15、D+=17、D=19、E+=21、E=剩余 的金字塔权重分配至 S+ / S / A+ / A / B+ / B / C+ / C / D+ / D / E+ / E 共 12 级。高档少、低档多,梯队边界随数据变化动态浮动,不设固定阈值。鼠标悬停梯队标签可查看精确综合分;勾选「显示综合分」可在梯队旁直接显示数值。综合分计算方式:主基准组加权平均(DeepSWE 35%/Vibe Code 15%/llm2014 10%/Code Arena·WebDev 15%/AI 能力·前端 10%/AI 能力·后端 10%,llm2014 与 AI 能力同为个人专项测试口径、权重较低,缺失榜单的权重自动回流至在场榜单),再减一致性折减(跨榜标准差越大折减越多,每点σ扣0.15分,上限2分)。列表默认按综合分容差分组排序:差距<1.5分的模型视为同档,同档内优先排列命中数多、跨榜一致性高的模型。
  • 「命中」表示该模型在对应基准组中进入榜单,5/5 表示五项基准(DeepSWE / Vibe Code / llm2014 / Code Arena·WebDev / AI 能力)均有排名。
  • DeepSWE 与 Vibe Code 为百分比,分数后的「$X」为该模型在对应基准的单次任务成本(美元,DeepSWE 为平均成本、Vibe Code 为单测成本); llm2014 为按各项目等级均值归一化的综合分(0-100,月内均值最高 100、最低 0,中间按等级差距线性分布;均值完全相同的模型按源站排名先后微调区分,保证人人不同分),其明细单元格为「扣分数/档位」,2026-08 起等级单元格可含单任务测试成本(如「7/A+(90.52)」表示扣 7 分、A 档、成本 ¥90.52); Code Arena · WebDev 为 LMArena 前端竞技场的 Elo 评分(社区匿名盲测投票,分值越高越好,矩阵列显示原始 Elo),参与综合分主基准组时按快照内 min-max 归一化到 0-100; AI 能力·前端/后端为 atmeplz 四方向榜的方向分(0-100,天然以 100 为参考,越高越好),前端=中式建筑 25%+体素山水 25%+前端网页 40%+黑洞模拟 10%,后端=超级 MES 100%。
  • 「—」表示该榜未收录此模型。DeepSWE 列分数后的 v1.1/v1.0 标识表示数据来源版本(v1.1=当前每日刷新,v1.0=历史榜单补充)。
  • 浅绿底色行表示跨榜命中数 ≥ 3 的模型;灰蓝底色行 + 「双榜」徽标表示恰好命中 2 个基准组的模型:逐榜与排名行模型比对成绩(统计各榜有多少个排名模型高于它,以较靠后的弱榜为准),落入与自身水平相符的名次区间,不计算综合分,梯队列仅显示「—」,序号列计「—」,不参与排名、不占用前30名额,仅跻身前30区间内时显示;模型名后 NEW 表示近 7 天内首次上榜(仅基于 DeepSWE/Vibe/llm2014 三基准判定)。
  • 点击表头可按该列排序(按某评测排序时仅显示该评测有数据的模型)。
  • 「显示全部模型」开关可展开全部命中≥2榜的模型(包含排名30之后的模型);总览矩阵不展示仅命中一榜的模型,请前往对应榜单页查看。 默认显示命中≥3个基准组且排名前30的模型,以及跻身前30区间的双榜模型(恰好命中 2 个基准组,按各榜成绩比对落入区间,不计算综合分)。
