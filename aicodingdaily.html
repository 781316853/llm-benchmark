阅读说明

要点速览 · 计分席位与口径可展开
  • 来源AI Coding Daily(aicodingdaily.com),主办方为独立开发者 Povilas Korop,不是被评厂商之一;每个模型在 7 个真实项目上跑 27 个 prompt,源站累计 2000+ 次运行。
  • 分数口径总分 0-70 = Laravel 代码质量 20 + React-TS 代码质量 20 + Bug Finding 10 + Edge-case Testing 20;每个 prompt 从项目全新副本起步,模型看不到隐藏测试,无人工反馈。
  • 混口径源站「Tested with」列显示每个模型跑在各自的 agent harness 上(Codex CLI / Claude Code / OpenCode / Cursor / Devin / Antigravity / DeepSeek Harness),分数同时反映模型能力与脚手架质量。
  • 计分与免责计入总览综合分(权重 8%)与命中数(分母 9);数据为快照,不代表绝对评价。
展开权重席位与成本说明
  • 权重席位按站内判据(主办方是否被评厂商自身)独立第三方实测榜计入综合分;因 harness 逐模型混杂、且与同为编码 agent 实测的 ModelDial(14%)存在重复计量,取 8% 压低,与 2026-09-24 无机酸前端实测入组时的处理同法。
  • 成本/耗时均为每 prompt 平均值,不是每模型整轮测试成本;源站对部分模型未给成本(显示「—」),这些条目不进散点图但仍在下表。
  • 更新频率源站按周更新,本页「源站发布」取页面 Last update 标注,「本站抓取」为每日刷新时间。
