13 题成绩明细

阅读说明

要点速览 · 权重席位与混口径可展开
  • 来源AI 十项全能·定时挑战赛(octathlon.wendystars.com),主办方为独立第三方,不是被评厂商之一;13 道题、10 个类别,单题限时 60–100 分钟,无人答疑、到时中止。
  • 分数口径每题折算 0–100 分,类别权重各 10%、类内各题平分,总分 0–100。7 道标准评判题由程序校验(Lean 编译、加速比、对局实力值、拆解步数、形状吻合度等),6 道主动设计题由 Claude Opus 5.5 与 GPT 6.1 Sol 各评一次、逐项取平均。
  • 混口径模型连同它自己的 agent harness 一起测(Claude Code / Codex / Qwen Code / Kimi Code / ZCode / OpenCode 等),分数同时反映模型能力与脚手架质量;两位评分员本身也在被评名单中。
  • 计分与免责计入总览综合分(权重 8%,「第三方实测」组)与命中数(分母 10);数据为快照,不代表绝对评价。
展开开销口径与题目清单
  • 开销订阅模型按每周额度折算订阅费,或按官方 API 等值与套餐价格比例折算;积分制套餐按档价折算;API 模型按官方标价计算;汇率与额度数据源见页脚。
  • Token / TPSToken 为该次全部 13 题的累计消耗;TPS 为源站记录的每秒输出 token 数,「—」表示源站未给。
